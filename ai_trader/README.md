# AI Trader — бот для фьючерсов Bybit с ИИ и Telegram Mini App

Сервис аренды торгового бота: клиент заходит в Telegram, открывает мини-апп,
торгует бесплатно на демо-счёте, а по подписке (Telegram Stars) подключает
свой Bybit по реферальной ссылке — и бот торгует на его аккаунте.

> ⚠️ **Риски.** Торговля фьючерсами с плечом может привести к потере всех средств.
> Бот не гарантирует прибыль. Перед запуском сервиса для клиентов проконсультируйтесь
> с юристом: в ряде стран автоматическая торговля на счетах клиентов требует лицензии.

## Как это устроено

```
Telegram-бот (aiogram) ──┐                         ┌── ИИ-аналитик (Claude)
  /start, оплата Stars    │                         │   режим рынка, веса стратегий,
                          ▼                         │   уроки и подстройка раз в сутки
Mini App (webapp/) ──► FastAPI (app/api.py) ──► EngineManager (app/engine/manager.py)
  тёмный UI, календарь     авторизация по            │
  доходности, настройки    подписи Telegram          ├── MarketHub: цены, свечи, ликвидации
                                                     │   (одна подписка на монету для всех)
                                                     └── UserWorker × N клиентов
                                                          ├─ Сетка (grid)
                                                          ├─ Тренд (откат к EMA20)
                                                          ├─ Отскок после ликвидаций
                                                          └─ RiskGuard + Learner
```

Всё работает в одном процессе: `uvicorn app.main:app`.

### Стратегии и распределение

| Стратегия | Когда работает | Сделки |
|---|---|---|
| **Сетка** | боковик | 6–10 лимитных уровней, прибыль с цикла ≈ шаг (0.2–2%) минус комиссии maker. Много мелких сделок |
| **Тренд** | тренд, ADX > 23 | вход после отката к EMA20 и подтверждающей свечи, тейк 1.0–1.2R |
| **Ликвидации** | высокая волатильность | вход на отскок после каскада ликвидаций, тейк до VWAP (1–2R) |

На каждой монете в каждый момент работает **одна** стратегия — та, у которой больше вес:
`вес = вес от ИИ × множитель обучения × включена ли стратегия у клиента`.

### Как бот «учится»

1. **Статистика результатов** (`strategy_stats`): для каждой связки
   *монета × стратегия × режим рынка* хранится экспоненциальное среднее результата в R
   по сделкам всех клиентов. Стратегии, которые теряют, получают множитель до 0.4
   (меньше капитала, реже выбираются), прибыльные — до 1.6.
2. **ИИ-анализ** каждые `AI_INTERVAL_MIN` минут по каждой монете: Claude получает
   индикаторы, ликвидации, funding, статистику обучения и уроки → возвращает режим,
   веса, направление и шаг сетки, множитель риска (строгий JSON по схеме).
3. **Ежедневный разбор** (00:05 UTC): Claude читает итоги сделок за сутки, пишет до 5
   уроков (они попадают в следующие анализы) и подстраивает параметры
   (`grid_step_atr`, `trend_rr`, `liq_threshold_mult`) — не больше чем на 20% за день
   и в жёстких границах.

ИИ **не отправляет ордера** и не может превысить лимиты риска — это делает код.
Без ключа Anthropic работает запасной алгоритм определения режима.

### Риск-профили

| | Консервативный | Сбалансированный | Агрессивный |
|---|---|---|---|
| Риск на направленную сделку | 0.3% | 0.5% | 1% |
| Плечо | 3x | 5x | 8x |
| Капитал под сетки | 30% | 45% | 60% |
| Макс. убыток одной сетки | 1.5% | 2.5% | 4% |
| Сеток / сделок одновременно | 2 / 1 | 3 / 2 | 4 / 3 |
| Дневной лимит убытка | 2% | 3% | 5% |
| Пауза после убытков подряд | 3 | 4 | 5 |

Объём уровня сетки рассчитывается так, чтобы даже при срабатывании стопа сетки
(все уровни заполнены + 1.5 шага) убыток не превысил лимит профиля.
**Следствие:** на маленьком депозите сетка по BTC не строится (минимальный лот
0.001 BTC не влезает в бюджет) — бот выберет монеты подешевле. Для сеток
по BTC/ETH рекомендуемый депозит — от 3–5 тыс. $.

### Безопасность ключей клиентов

- Ключи шифруются (Fernet, `ENCRYPTION_KEY`) и никогда не отдаются во фронтенд.
- При подключении ключ проверяется через Bybit: **ключ с правом вывода (Withdraw)
  отклоняется**, read-only тоже.
- Реальный счёт принимается, только если UID клиента — ваш реферал
  (проверка через партнёрский API Bybit `aff-customer-info`).
- API мини-аппа принимает только запросы с валидной подписью Telegram `initData`.

## Развёртывание

### 1. Подготовка

1. Создайте бота у **@BotFather**, получите `BOT_TOKEN`.
2. Нужен сервер (VPS) с доменом и HTTPS — Telegram открывает мини-аппы только по HTTPS.
3. Ключ Anthropic: console.anthropic.com → API Keys.
4. Партнёрский API-ключ Bybit (read-only) на аккаунте, к которому привязана реферальная программа.

### 2. Установка

```bash
git clone -b claude/tradingview-mcp-jackson-setup-d9mo5s https://github.com/trendq1/bot.git
cd bot/ai_trader
python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m app.security          # скопируйте ключ в ENCRYPTION_KEY
nano .env                       # заполните остальное
```

### 3. Запуск

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

HTTPS через Caddy (`/etc/caddy/Caddyfile`):
```
your-domain.com {
    reverse_proxy 127.0.0.1:8000
}
```

В @BotFather: `/mybots → Bot Settings → Menu Button` (бот ставит кнопку сам при старте)
и `/newapp`, если хотите ссылку вида `t.me/yourbot/app`. `WEBAPP_URL` = `https://your-domain.com/app/`.

Для постоянной работы — systemd-сервис или Docker. Для многих клиентов переключитесь
на PostgreSQL (`DATABASE_URL=postgresql+asyncpg://...`, `pip install asyncpg`).

### 4. Локальная отладка интерфейса без Telegram

```bash
BOT_TOKEN= DEV_USER_ID=1 ENGINE_ENABLED=0 uvicorn app.main:app --port 8000
# откройте http://localhost:8000/app/
```
`DEV_USER_ID` работает только при пустом `BOT_TOKEN` — в продакшене он отключён.

### Тесты

```bash
pip install pytest && python -m pytest -q tests
```

## Стоимость ИИ

Анализ общий для всех клиентов — стоимость не растёт с их числом.
Ориентир: 10 монет × анализ раз в 30 минут ≈ 480 запросов в сутки.
На `claude-opus-5` это порядка $10–15 в день, на `claude-sonnet-5` — примерно в 2.5 раза дешевле.
Регулируется `AI_MODEL` и `AI_INTERVAL_MIN`.

## Что проверить перед запуском для клиентов

1. Неделя на демо-счёте (paper) — смотрите календарь и статистику по стратегиям.
2. Затем демо-счёт Bybit (режим «Демо-счёт Bybit» при подключении ключа).
3. Только потом реальный счёт, начиная с консервативного профиля.
