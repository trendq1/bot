# AI Trader — бот для фьючерсов Bybit с ИИ, Telegram Mini App и админ-панелью

Сервис аренды торгового бота. Клиент заходит в Telegram-бота, открывает мини-апп,
бесплатно торгует на демо-счёте, а по подписке (Telegram Stars) подключает свой
Bybit по вашей реферальной ссылке — и бот торгует на его аккаунте.
Вы управляете всем из браузерной админ-панели.

> ⚠️ Торговля фьючерсами с плечом может привести к потере всех средств. Бот не гарантирует
> прибыль. Перед запуском для клиентов проконсультируйтесь с юристом: в ряде стран
> автоматическая торговля на счетах клиентов требует лицензии.

| Адрес | Что это |
|---|---|
| `/setup` | Мастер установки (только при первом запуске) |
| `/admin` | Админ-панель |
| `/app/` | Мини-апп для Telegram (этот адрес указывается в настройках бота) |

## Что нужно

- **VPS/VDS-сервер** с Ubuntu 22.04+ / Debian 12+ (от 1 ГБ RAM), желательно с панелью
  (aaPanel, FastPanel, ISPmanager, HestiaCP) — через неё удобно загружать файлы и создавать базу.
- **Домен с HTTPS** — Telegram открывает мини-аппы только по HTTPS (в панели: Let's Encrypt).
- **MySQL 5.7+ или MariaDB 10.3+**.
- Python 3.10+ (в Ubuntu 22.04+ уже есть).

> **Обычный виртуальный хостинг (cPanel «Setup Python App», Beget shared и т.п.) не подойдёт.**
> Боту нужно работать 24/7 и держать постоянное соединение с биржей и Telegram, а такие
> хостинги останавливают процессы. Подойдёт любой VPS от ~5 $/мес.

## Установка через файловый менеджер

### 1. База данных
В панели хостинга → «Базы данных» → создать базу, например `aitrader`, пользователя и пароль.
Кодировка — **utf8mb4**. Запишите имя базы, пользователя и пароль.

### 2. Загрузка файлов
1. Файловый менеджер панели → папка сайта (например `/www/wwwroot/aitrader` или `/var/www/aitrader`).
2. **Загрузить** `ai_trader.zip` → **Распаковать** (Extract). Внутри должны оказаться
   `run.py`, `install.sh`, папки `app`, `admin`, `webapp`.

### 3. Запуск
Откройте **терминал** панели (или SSH), перейдите в папку и запустите установщик:
```bash
cd /www/wwwroot/aitrader
sudo bash install.sh
```
Скрипт создаст виртуальное окружение, установит зависимости и зарегистрирует
службу `aitrader`: она запускается сама после перезагрузки сервера и перезапускается при сбое.

<details><summary>aaPanel без терминала</summary>

«Сайт» → «Python-проект» → «Добавить»: путь — папка проекта, файл запуска — `run.py`,
порт — `8000`, отметить «установить зависимости» (`requirements.txt`). Запустить.
</details>

### 4. Домен → приложение
В панели для домена включите **обратный прокси** (reverse proxy) на `http://127.0.0.1:8000`
и выпустите SSL-сертификат. Пример для nginx:
```nginx
location / {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

### 5. Мастер установки
Откройте `https://ваш-домен/setup`:
1. **Код установки** — в файле `SETUP_CODE.txt` в папке проекта (откройте файловым менеджером).
2. **Данные MySQL** из шага 1 → «Проверить подключение».
3. **Логин и пароль администратора.**
4. По желанию сразу: токен бота, ключ Anthropic (можно позже в админке).

После «Установить» приложение само создаст таблицы, файл `.env` с ключами шифрования,
перезапустится и откроет **админ-панель**.

### 6. Настройки в админ-панели
«🔑 Настройки и ключи»: токен бота (@BotFather), адрес мини-аппа `https://ваш-домен/app/`,
ключ Anthropic, реферальная ссылка и партнёрский API-ключ Bybit, цены в звёздах, монеты.
После изменения полей с пометкой «нужен перезапуск» нажмите **«Перезапустить приложение»**.

Кнопка «AI Trader» в меню Telegram-бота ставится автоматически.

## База данных

MySQL/MariaDB, 15 таблиц (создаются автоматически; для ручного импорта через phpMyAdmin —
`sql/schema.sql`):

`users` клиенты · `bot_settings` настройки ботов · `exchange_accounts` подключения Bybit
(ключи зашифрованы) · `trades` сделки · `equity_snapshots` баланс для графиков ·
`payments` оплаты · `finance_entries` ручные доходы/расходы · `ai_usage` расход токенов ИИ ·
`ai_insights` анализы рынка · `lessons` уроки ИИ · `strategy_stats` статистика обучения ·
`symbol_tuning` подстроенные параметры · `app_settings` настройки и ключи ·
`admin_users` администраторы · `audit_log` журнал действий.

**Резервная копия:** в панели → базы данных → «Резервная копия», плюс файл `.env`
(без него зашифрованные ключи не расшифровать — храните его копию отдельно).

## Как работает бот

**Стратегии.** Сетка (много мелких сделок в боковике), тренд (вход после отката к EMA20,
тейк 1–1.2R), отскок после ликвидаций. На монете в каждый момент одна стратегия — с наибольшим весом:
`вес от ИИ × множитель обучения × включена ли у клиента`.

**ИИ (Claude).** Раз в `ai_interval_min` минут по каждой монете определяет режим рынка,
веса стратегий, направление и шаг сетки, множитель риска. Раз в сутки разбирает сделки,
пишет уроки и подстраивает параметры (не больше ±20% за день, в жёстких границах).
ИИ не отправляет ордера и не может обойти лимиты риска. Без ключа работает запасной алгоритм.

**Обучение.** По каждой связке «монета × стратегия × режим рынка» копится результат всех
клиентов; убыточные стратегии получают до 0.4× капитала, прибыльные — до 1.6×.

**Риск-профили:**

| | Консервативный | Сбалансированный | Агрессивный |
|---|---|---|---|
| Риск на сделку | 0.3% | 0.5% | 1% |
| Плечо | 3x | 5x | 8x |
| Капитал под сетки | 30% | 45% | 60% |
| Макс. убыток сетки | 1.5% | 2.5% | 4% |
| Дневной лимит убытка | 2% | 3% | 5% |

На маленьком депозите сетка по BTC не строится — минимальный лот не помещается в лимит риска.
Для сеток по BTC/ETH нужен депозит от 3–5 тыс. $.

**Безопасность.** API-ключи клиентов и ваши ключи шифруются (Fernet); ключ Bybit с правом
вывода отклоняется; реальный счёт — только для ваших рефералов (партнёрский API Bybit);
мини-апп принимает только запросы с подписью Telegram; админка — пароль (PBKDF2),
подписанная cookie, защита от перебора и CSRF; мастер установки закрыт одноразовым кодом.

## Обслуживание

| Задача | Как |
|---|---|
| Перезапуск | админка → Настройки → «Перезапустить» или `sudo systemctl restart aitrader` |
| Статус / логи | `systemctl status aitrader` · файл `logs/app.log` · админка → Журнал |
| Обновление | загрузить новый zip, распаковать поверх (`.env` и база сохраняются), перезапустить |
| Локальная проверка на Windows | `start.bat` → http://localhost:8000/setup |

## Стоимость ИИ

Анализ общий для всех клиентов. 10 монет × раз в 30 минут ≈ 480 запросов в сутки:
~10–15 $/день на `claude-opus-5`, примерно в 2.5 раза дешевле на `claude-sonnet-5`.
Фактический расход виден в админке → «Доходы и расходы».
