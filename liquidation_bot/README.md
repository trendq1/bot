# Liquidation Reversal Bot — Bybit USDT Perpetual (API v5)

Бот ловит **отскок после каскада ликвидаций**. Переписан с нуля по идее бота
Bybit-Futures-Bot, но без его опасных мест (стоп, который уезжает за ценой,
усреднение без ограничений, тейк 0.66% против стопа 20%).

> ⚠️ Торговля фьючерсами с плечом может привести к потере депозита. Бот — инструмент,
> а не гарантия прибыли. Начинай с режима `paper`, потом `demo`, и только потом `live`.

## Как работает стратегия

1. Бот слушает **все ликвидации на Bybit** (`allLiquidation`) по списку монет.
2. **Каскад** — сумма ликвидаций одной стороны за 60 секунд больше порога
   (`min_cascade_usd`, например 1 млн USDT для BTC).
3. **Цена ушла далеко от VWAP** — минимум на 2 ATR (5-минутные свечи, VWAP за 4 часа).
4. **Каскад затих** — 5 секунд без новых ликвидаций (не ловим падающий нож).
5. **Есть отскок** — цена отошла от экстремума на 0.15 ATR.
6. **Вход в обратную сторону**: ликвидировали лонги → LONG, ликвидировали шорты → SHORT.
   - **Стоп** — за экстремумом каскада + 0.5 ATR (от 0.3% до 3% от цены, шире — пропуск).
   - **Тейк** — возврат к VWAP, но не ближе 1.5R и не дальше 3R. Если до VWAP меньше 1.5R — пропуск.
   - Стоп и тейк ставятся **на бирже сразу вместе с ордером**, даже если бот упадёт.

**Сопровождение и защита депозита:**

| Правило | По умолчанию |
|---|---|
| Риск на сделку | 0.5% депозита |
| Максимальное плечо | 5x |
| Одновременно позиций | 3 |
| Сделок в день | 10 |
| Дневной лимит убытка | 3% → торговля стоп до следующего дня (UTC) |
| Убытков подряд | 3 → пауза 4 часа |
| Пауза по монете после сигнала | 30 минут |
| Безубыток | стоп переносится на вход при +1R |
| Максимальное время в сделке | 120 минут → закрытие по рынку |

Усреднения (DCA) **нет специально**: оно увеличивает риск в сделке, которая уже идёт против тебя.

## Установка (Windows, PowerShell)

```powershell
cd $env:USERPROFILE
git clone -b claude/tradingview-mcp-jackson-setup-d9mo5s https://github.com/trendq1/bot.git trendq1-bot
cd trendq1-bot\liquidation_bot

```

```powershell

```

## Режимы (`"mode"` в config.json)

| Режим | Что происходит | Ключи |
|---|---|---|
| `paper` | Сделки виртуальные, на реальных ценах Bybit, с комиссией 0.055% | Не нужны |
| `demo` | Реальные ордера на **демо-счёте Bybit** (виртуальные деньги) | Демо-ключ |
| `testnet` | Тестовая сеть Bybit (цены и ликвидации там не настоящие) | Ключ testnet |
| `live` | **Реальные деньги.** Нужно ещё `"i_understand_live_risk": true` | Боевой ключ |

### 1. Paper — запусти первым

```powershell
python bot.py
```

Оставь на **несколько дней**. Смотри `bot.log` (все ликвидации, сигналы, причины пропуска)
и `trades.csv` (журнал сделок с PnL).

### 2. Demo — реальные ордера без реальных денег

1. На bybit.com переключись в **Demo Trading** → профиль → **API** → создай ключ
   (права: *Contract — Orders, Positions*). **Вывод средств не включай.**
2. В `config.json` поставь `"mode": "demo"`.
3. Задай ключи в переменных окружения (не в файлах!):
   ```powershell
   setx BYBIT_API_KEY "ключ"
   setx BYBIT_API_SECRET "секрет"
   ```
   Закрой и открой PowerShell заново, затем `python bot.py`.

### 3. Live — только после 2–4 недель в плюсе на demo

Новый ключ на основном аккаунте (без права вывода, лучше с привязкой к IP),
`"mode": "live"`, `"i_understand_live_risk": true`. Начни с минимального риска — `"risk_per_trade_pct": 0.25`.

## Настройки (config.json)

- `symbols` — монеты (формат `BTCUSDT`). Несуществующие на Bybit пропускаются.
- `min_cascade_usd` — порог каскада по монетам, `default` — для остальных. Главная настройка:
  слишком низкий порог = много шума, слишком высокий = редкие сигналы. Подбирай по `bot.log`.
- `log_liquidations_from_usd` — с какой суммы писать ликвидации в лог.
- `indicators.interval` / `vwap_bars` — таймфрейм свечей и длина VWAP (48 × 5 мин = 4 часа).
- `strategy.*` — параметры входа (описаны выше).
- `risk.*` — лимиты риска (таблица выше).
- `paper.balance` / `fee_pct` — виртуальный депозит и комиссия для режима paper.

Бот работает в **one-way режиме** позиций (переключает сам при старте) и выставляет плечо
по каждой монете. Позиции, открытые вручную, он не трогает, но по той же монете не входит.
